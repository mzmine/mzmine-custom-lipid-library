mzmine custom lipid library

Custom lipid classes for rule-based lipid annotation in mzmine, shared by the community. Download them and import them in mzmine.

How to use Submit a class

How to use these classes in mzmine

  1. Download one class, or select several and download them as one file.
  2. In mzmine, open Lipid annotation → Custom lipid classes → Import… and choose the downloaded .json file.
  3. Check the classes you want to search for and run the annotation.

Share your own class

  1. Build and test your class in mzmine, then use Export… to save it as .json.
  2. Open a submission, paste the file and describe the class. The repository checks the class automatically and a maintainer reviews it.
  3. You keep the right to use your class for your own research and are named as its author.

Built-in classes are the classes that ship with mzmine. They are listed as templates to build your own classes from.
